# 平均フォント

日本語オープンライセンス書体 **229書体** のグリフをビットマップ描画して
ピクセル平均したフォント。

## ダウンロード

- `AverageFont-Regular.ttf` — 最新 v5（18414字、7.5MB）。インストールして使う
- `AverageFont-Regular-v5-229fonts-18414chars.ttf` — v5 と同じもの。Releases にもある
- 旧版も残してある：v4（10305字）、v3（2290字）、v2（174字）、v1（100書体）

## v5 の文字（18414字）

- 選定：229書体のうち **20書体以上がグリフを持つ可視文字**（proper20）。
  v4 の 10305字を全部含み、半角句読点・全角英数字・ギリシア・キリル・
  ラテン拡張・矢印・数学記号・囲み文字・JIS X 0212漢字・CJK拡張の一部など
  8109字を追加。
- 内訳：漢字 13962字、ひらがな 91字、カタカナ 95字、半角カタカナ 121字、他。
- 入ってないもの：20書体未満の字（CJK拡張Bの大半、ハングルなど。
  1ファミリーだけのコピーは「平均」にならないので入れない）、
  結合文字・不可視文字。10〜19書体の帯 1133字は v6 検討。
- 検証：空グリフ 0、豆腐 0。寄与数は min 20・中央値 122・max 229。

## 手法

1. 229書体で各文字を 256×256px に描画
2. 画素値を平均（グリフのない書体は除外）
3. 適応しきい値で二値化 → 輪郭抽出 → TTF化（直線の多角形近似、ヒンティングなし）

## 制限

- 平均化でグリフはぼやける。輪郭は直線の多角形近似で、拡大するとカクつく。
  ベースラインは完全一致ではないので本文組版には向かない。見出し・実験向け。
- 全角＠は小さめに潰れる、ローマ数字や括弧は細い。豆腐ではない。

## ライセンス

- 元書体は大半が SIL OFL 1.1（一部 IPA・VL・Migu 等、詳細は `SOURCES.md`）。
  平均グリフ・TTF は 229書体の画素統計からの派生物。
  「Average Font」は新規名で、OFL の Reserved Font Name は使っていない。

## 再現

```sh
cd work
./venv/bin/python render_average_v5.py  # 新規 8109字を平均化（約25分）
./venv/bin/python build_ttf_v5.py       # TTF 生成
./venv/bin/python make_sheets_v5.py     # シート・テスト・ビューワー生成
```
